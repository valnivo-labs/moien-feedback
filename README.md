# Moien — feedback

**Moien** is a free app for learning Luxembourgish, from A1 to C2:
**https://moien-lu.web.app**

This repository holds no code. It exists so that anyone using the app can report
a problem or suggest a correction. Please open an issue:

- **[Report a mistake in the course](../../issues/new?template=content.yml)** — a wrong
  translation, a spelling that does not follow the official orthography or the
  [LOD](https://lod.lu), a misleading grammar note.
- **[Report a bug](../../issues/new?template=bug.yml)** — something in the app does not work.
- **[Suggest something](../../issues/new?template=idea.yml)** — a lesson, a word, a feature.

Corrections from native speakers are the most valuable thing this project can
receive. Merci villmools!

---

Reports are welcome in English, French, German, Luxembourgish, Portuguese,
Spanish, Italian or Arabic.
